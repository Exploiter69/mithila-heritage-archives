# Media and rights

Mithila Heritage Archives separates media records from cultural claims.

## Images

Wikimedia Commons images are external references. Each image record is expected to retain:

- Commons file page
- contributor/credit
- licence label
- licence URL
- display/source URL
- caption and any use caveat

The archive must never infer a licence or contributor merely from an image URL.

## Audio

Audio is referenced through external provider streams. The archive does not copy or redistribute those recordings.

External playback identifiers are treated as deterministic locators, not as proof that the associated cultural claim is correct.

## Removal and correction

Rights holders or contributors who identify an incorrect attribution, licence or use context should report the record and provide the relevant source information.

The editorial system should preserve the correction trail rather than silently rewriting history.
