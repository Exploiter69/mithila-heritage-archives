# Community contributions

The archive accepts proposals, not direct anonymous writes.

A proposal should contain:
- target canonical record ID, or new-record;
- proposed field/value;
- reason for the change;
- source citation;
- source URL when publicly available;
- exact locator/page/section when available;
- contributor attribution;
- media attribution/license when media is proposed;
- confidence/status requested;
- date of submission.

A proposal is not evidence by itself. Editors must verify the supporting source before changing canonical records.

## Safe boundary
Because this project intentionally has no authentication or database, the public site does not expose a mutation endpoint. Proposals can be exchanged as JSON and reviewed offline. This prevents an unauthenticated visitor from changing canonical heritage data.

## Publication workflow
1. Create proposal.
2. Attach evidence.
3. Editorial review.
4. Verify claim.
5. Update canonical source-controlled data.
6. Run archive validation and provenance audit.
7. Publish.
8. Preserve the proposal/review trail in repository history.
