# Archive release 2026.10.0

Release date: 2026-10-08.

This is the current public software/data snapshot of Mithila Heritage Archives. The published catalogue contains 754 records, including 43 music song/tradition records.

## Distribution

- JSON: `/api/archive`
- Research JSON: `/api/archive?version=2`
- CSV records: `/api/archive?format=csv`
- Search API: `/api/search`
- Research & Data page: `/research`

## Interpretation

The release identifier is a reproducibility marker for the published Git dataset and application. It is not a scholarly certification.

Each record remains authoritative for its own:
- verification status
- provenance assertions
- source attribution
- uncertainty/dispute state
- media rights and preservation status

Source-by-source human verification, precise edition/page locators and disputed-claim resolution remain ongoing research work.

## Reproducibility

The Git commit that contains this release is the immutable source snapshot. The public API is a read-only projection of that canonical dataset.


## Music collection note

The 2026.10 snapshot includes a research-first music catalogue covering 42 song/tradition records. External recordings are playback leads only; unavailable or unverified links are not treated as preservation copies. Records without current recordings remain part of the published catalogue.
