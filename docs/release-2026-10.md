# Archive release 2026.10.0

This is the current public software/data snapshot of Mithila Heritage Archives.

## Distribution

- JSON: `/api/archive`
- Research JSON: `/api/archive?version=2`
- CSV records: `/api/archive?format=csv`

## Interpretation

The release identifier is a reproducibility marker for the published Git dataset and application. It is not a scholarly certification.

Each record remains authoritative for its own:
- verification status
- provenance assertions
- source attribution
- uncertainty/dispute state
- media rights and preservation status

Source-by-source human verification, precise edition/page locators and disputed-claim resolution remain ongoing research work.

## Reproducibility

The Git commit that contains this release is the immutable source snapshot. The public API is a read-only projection of that canonical dataset.
