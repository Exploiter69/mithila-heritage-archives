# Mithila Legacy Archive

Build v0.1 of “Mithila Digital Archive”, a serious, modern cultural archive dedicated specifically to Mithila and the Maithili language. Create Home, Literature, Authors, Language, Dictionary, Proverbs, Art & Heritage, Music, and About / Sources pages. Use a calm contemporary editorial-archive design, with subtle Mithila visual identity, ivory/terracotta/muted gold/deep ink palette, excellent Devanagari plus Latin typography, mobile-first responsive navigation, restrained motion, and no generic SaaS/dashboard aesthetic. Make it content-driven with reusable cards/components, clean URLs, SEO-ready structure, search-ready architecture, and visible source/attribution fields. Seed each area with thoughtful structured example content. Do not add authentication, payments, social features, comments, AI chatbot, backend, or database.
